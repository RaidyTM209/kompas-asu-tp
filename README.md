# КОМПАС АСУ ТП

Переносимый скилл для преподавателя. Корень Git-репозитория — эта папка с SKILL.md. При переносе сохраняйте подпапки и исходные имена. Материалы преподавателя и нормативы входят в комплект; выбирайте видимость репозитория с учётом прав на эти файлы.

## Установка из Git (Codex на Windows)

После размещения содержимого этой папки в корне вашего репозитория выполните в PowerShell:

```powershell
$repo = Read-Host "URL вашего Git-репозитория"
$skills = Join-Path $HOME ".agents/skills"
New-Item -ItemType Directory -Force $skills | Out-Null
git clone $repo (Join-Path $skills "kompas-asu-tp")
```

Для обновления выполните `git -C "$HOME/.agents/skills/kompas-asu-tp" pull --ff-only`. В новом сеансе вызовите `$kompas-asu-tp` и передайте задание. Можно также открыть эту папку как проект и попросить Codex прочитать SKILL.md. Для выпуска CDW требуется доступ к КОМПАС на Windows.

## Что внутри

SKILL.md задаёт последовательность выпуска и карту учебных материалов. references/cherchenie.md содержит практикум по работе мышью и через COM. references/project.schema.json описывает минимальный контракт реестра. Применимые дополнительные поля из инструкции (единицы, уставки, нагрузки, длины, размеры, вырезы, ссылки на страницы и т. д.) допускаются. В equipment добавляйте также граничные узлы и узлы разветвления. Байпас опишите отдельными участками между точками отбора и возврата. Формируйте легенду по реально используемым кодам сред.

## Проверка (Python 3.9+, стандартная библиотека)

```powershell
python scripts/check_project.py examples/project.demo.json --bom bom.csv
python scripts/check_project.py путь/к/project.json
python scripts/check_boundary.py svs.csv mks.csv
```

Первый запуск демонстрирует три физических датчика одного исполнения, одну строку закупки и числовое количество 3. DEMO — тестовые значения. CSV из --bom служит промежуточной таблицей для подсчёта, полную форму спецификации и коммерческую таблицу формируйте по SKILL.md. Мерные материалы суммируются в одной единице. Результат проверки структуры не подтверждает реальность артикула, актуальность цены, правильность геометрии или полноту проекта.

Для сверки СВС/МКС независимо извлеките из каждого сохранённого листа UTF-8 CSV с разделителем «;» и заголовком `panel;cable;core;strip;terminal;circuit`. Одна строка — оконцевание внешней жилы на стороне щита. В panel указывайте уникальный щит. Проверяются наличие жил на обоих листах, клеммник, зажим и цепь. Код выхода 0 — совпадение, ненулевой — различия либо ошибка входных данных.
