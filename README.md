# Учебные проекты АСУ ТП в КОМПАС-3D

Скилл для преподавателей автоматизации, которые готовят образцы курсовых и дипломных проектов. Codex читает задание, строит функциональную схему, подбирает приборы по паспортам и ведёт единый реестр позиций для чертежей, спецификации и пояснительной записки Word.

| Режим | Состав проекта |
|---|---|
| Курсовой | Функциональная схема, электрическая принципиальная схема, спецификация с закупочной таблицей, пояснительная записка |
| Дипломный | Курсовой комплект, фасад и монтажная панель щита, перечень содержимого и таблица надписей, затем СВС и МКС |

## Установка на Windows

Понадобятся Codex и Git. Для выпуска редактируемых CDW нужен установленный КОМПАС-3D с доступом через интерфейс или Python + COM. Для проверочных скриптов достаточно Python 3.9 или новее.

```powershell
$skills = Join-Path $HOME ".agents/skills"
New-Item -ItemType Directory -Force $skills | Out-Null
git clone https://github.com/RaidyTM209/kompas-asu-tp.git "$skills/kompas-asu-tp"
```

## Первый проект

Откройте в Codex рабочую папку проекта. Приложите задание, исходную технологическую схему и применимые стандарты. Полные тексты нормативов и авторские учебные чертежи предоставляются пользователем отдельно. Карта папок и перечень ДСТУ приведены в [инструкции](SKILL.md).

Пример запроса:

> $kompas-asu-tp Подготовь курсовой проект автоматизации уровня воды в баке по приложенному заданию. Начни с функциональной схемы. Для датчика укажи исполнение, обоснование диапазона, паспорт и источник цены. Оформи записку на украинском.

## Проверка на демонстрационных данных

Следующие команды можно выполнить сразу после установки, в том числе без КОМПАС:

```powershell
Set-Location "$HOME/.agents/skills/kompas-asu-tp"
python scripts/check_project.py examples/project.demo.json --bom "$env:TEMP/kompas-bom.csv"
```

В CSV появится одна строка для трёх экземпляров одного тестового датчика. В графе позиций будут `1А, 2А, 3А`, в графе количества — `3`. Для собственного проекта передайте скрипту свой `project.json`. Он проверяет структуру, ссылки на приборы и клеммы. Паспортные характеристики, цены и качество чертежей требуют отдельной сверки.

Для проверки дипломного комплекта подготовьте две независимые выгрузки с сохранённых листов СВС и МКС. Формат — CSV в UTF-8 с разделителем `;`, по одной строке на внешнюю жилу у щита. Заголовок — `panel;cable;core;strip;terminal;circuit`. Команда `python scripts/check_boundary.py svs.csv mks.csv` перечислит расхождения по клеммнику, зажиму и цепи.
