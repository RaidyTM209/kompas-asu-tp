# Проектирование учебного комплекта АСУ ТП

## Файлы для работы

Пути относительны папке этого SKILL.md. Выполняй последовательность выпуска ниже. Перед черчением прочитай references/cherchenie.md (авторская редакция SKILL2_1). Применяй её приёмы с учётом конкретной задачи: формат листа, размеры рамок и примерные модели сверяй с исходными документами. При конфликте приоритет имеют задание и применимый стандарт.
Для символов открой 01_normy/DSTU/11-dstu-b-a.2.4-16-2008.pdf, для развёрнутой ФСА, щитов и проводок — 01_normy/DSTU/dsty_b_a.2.4-3-2009.pdf, для Э3 — 01_normy/DSTU/61479.doc, для спецификации — 01_normy/DSTU/dsty_b_a.2.4-10-2009.pdf, для записки — 01_normy/DSTU/3008-2015.pdf.

Создавай отдельный project.json для каждого задания. Используй структуру references/project.schema.json, пример заполнения examples/project.demo.json и команды README.md. В черновике допускаются незаполненные данные; перед выпуском проверь минимальный контракт scripts/check_project.py. Процессные среды, оборудование и участки трубопроводов храни в media, equipment и pipelines. Уставки и паспортные данные добавляй по конкретному контуру. Функции ПЛК записывай в loops; физический контроллер закупается по составу исполнения.
Для штучных изделий один id соответствует одной позиции. Группируй по изготовителю и полному заказному коду: в графу позиций выведи все обозначения через запятую, в графу количества — число экземпляров. Мерные материалы записывай в materials с единицей и обоснованным количеством. Командой --bom проверь итоговые строки. Для диплома дополнительно выполни scripts/check_boundary.py над независимыми выгрузками сохранённых СВС и МКС.

## При запуске

Если режим не указан, предложи тест с одним выбором: 1 — курсовой, 2 — дипломный. Если процесс не задан, предложи учебные варианты (например, уровень воды в баке или температура в теплообменнике) и свободный ответ. Уточняй только отсутствующие существенные данные, группируя вопросы в короткие тесты. Для учебных исходных данных указывай допущения. Веди диалог на языке преподавателя, оформляй документы на украинском, если преподаватель не выбрал другой язык.

### Обязательная последовательность выпуска

1. Прочитай полное задание и исходную ТХ. Зафиксируй заданные среды, режимы, места измерения, допуски, уставки и границы объекта. Отметь недостающие исходные данные.
2. Первой начерти рабочую ФСА: аппараты, потоки, точки измерения, регулирующие органы, диапазоны и функции контуров. Создай черновой реестр с позициями и требованиями.
3. Для каждой позиции выполни реальный подбор по правилам ниже. Внеси проверенные исполнения в реестр, обнови и выпусти ФСА. Зафиксируй версию до начала электрической схемы.
4. По выбранным исполнениям и паспортным клеммам начерти электрическую принципиальную схему.
5. Выпусти спецификацию, затем пояснительную записку DOCX. В курсовом режиме на этом завершается разработка; проведи приёмку.
6. В дипломном режиме после записки разработай общий вид щита спереди и сзади, монтажную панель, перечень содержимого и таблицу надписей. Предпоследней разработай СВС, последней — МКС. Сверь их на границе клеммного ряда. При уточнении клемм, кабелей и метража обнови реестр и зависимые документы той же редакции, включая спецификацию и записку.

### Подбор и коммерческие данные

Для каждого датчика сопоставь рабочий минимум, норму и максимум, предусмотренные отклонения, требуемую погрешность и быстродействие с паспортом конкретного исполнения. Различай допустимую температуру среды, диапазон чувствительного элемента и настроенную шкалу преобразователя. Учитывай среду, давление, материалы, монтаж, питание, выход, вход контроллера и суммарную погрешность. При норме около 29 °C сначала выясни границы процесса и требуемую точность. Сравни подходящие низкотемпературные исполнения; обоснуй высокотемпературное исполнение только при реальной необходимости. Для давления проверь тип давления, для уровня — свойства среды и геометрию, для расхода — среду, диаметр и рабочие расходы.

Проверь полный заказной код по паспорту изготовителя и найди предложение поставщика именно на это исполнение. В components добавь поля manufacturer, order_code, datasheet_url_or_file, datasheet_page, selection_reason, supplier, offer_url_or_quote, unit_price, currency, price_unit, vat_status, checked_date и availability. Отдельно учти обязательные преобразователи и аксессуары. Используй рынок и валюту задания; явно указывай принятые допущения. При цене по запросу сохрани поставщика, ссылку и этот статус, числовое поле оставь пустым. Для полного ценового комплекта найди проверяемое предложение либо технически равноценную доступную модель. Не переноси цену сходного артикула. Помечай нерешённые позиции до выпуска эталона.

Выведи сведения о цене за единицу, валюте, дате и поставщике по позициям в отдельной закупочной таблице при спецификации. Сохрани форму нормативного листа и назначение граф массы и примечаний. Экономический раздел в записку не включай.

## Подготовь источники

Открой приложения по названиям и проверь титульные страницы. Для каждого вида документа запиши файл, редакцию, пункт, таблицу или приложение, по которым его проверяешь. Для графических форм просмотри саму страницу. Используй только приложенные нормативы. Паспорта изготовителей используй для технических характеристик и распиновки. Студенческие работы используй как образцы композиции и глубины изложения.

| Документ | С чем сверять |
|---|---|
| Функциональная схема | ДСТУ Б А.2.4-16:2008 для символов и буквенных функций, ДСТУ Б А.2.4-3:2009 для выполнения листа |
| Электрическая принципиальная | ДСТУ ГОСТ 2.702:2013, в приложениях встречается под именем 61479.doc |
| СВС, МКС, общий вид щита | ДСТУ Б А.2.4-3:2009, в частности п. 5.3.2–5.3.3 для общего вида; для таблицы надписей используй форму 6 приложения П |
| Заказная спецификация | ДСТУ Б А.2.4-10:2009 |
| Записка | ДСТУ 3008:2015, требования задания и структура приложенных работ Гужвы и Гнідко |

Если отдельный норматив отсутствует, запроси его у преподавателя. Продолжай независимые листы, зависимую форму обозначь как проект до сверки. Не приписывай стандарту размеры, правила кафедры и обозначения из штампа примера без проверки.

## Создай единственный источник данных

Сначала определи объект, границы, потоки, параметры, единицы, рабочие диапазоны и функции контуров. Подбери конкретные исполнения. Для выпуска ФСА сохрани UTF-8 project.json со следующими коллекциями:

- components — уникальный id экземпляра, точное позиционное обозначение, тип, изготовитель, полный заказной код, паспорт и страница, функция, место, группа спецификации, единица (одна запись на физический экземпляр), питание, входы/выходы, клеммы, габариты и вырез при необходимости.
- loops — номер, величина, уставки с единицами и основанием, ссылки на id измерителя, контроллера и исполнительного органа по фактической функции. Для сигнализации запиши условие, получателя, квитирование, возврат.
- connections — id цепи и провода, концы в виде id изделия и заводской клеммы, тип сигнала, полярность, кабель и жила. Для кабеля задай маршрут, длину в метрах и основание расчёта; храни расчётный запас отдельно.
- placement и labels — щит, поверхность, координаты в мм, ориентация, ссылка на изделие, номер рамки и точный текст. Привяжи выноску сборочного вида к позиции перечня.
- documents — состав выбранного комплекта, шифры, редакция, применимые позиции и источники.

Различай id экземпляра, обозначение на схеме и артикул закупки. Катушка и контакты KM1 ссылаются на одно изделие. У привода и клапана проверь самостоятельные заказные коды либо комплектный артикул. Проверь диапазон датчика, совместимость выхода со входом и питание. Для Pt100 используй характеристику сопротивления и действительную схему подключения. При неизвестном исполнении запроси паспорт или подбери проверенную замену до фиксации реестра.

Проверь уникальность позиций, существование ссылок и клемм, одинаковое написание кириллических суффиксов 1А, 1Б, 1В для новых листов. Зафиксируй SHA-256 файла. Все генераторы читают одну версию. Любое изменение начинается с реестра и повторного выпуска зависимых листов.

## Построй редактируемые листы

На Windows определи установленную версию КОМПАС, доступные шаблоны, библиотеки и COM-интерфейс по локальному SDK. Через Python и pywin32 подключись с зарегистрированным ProgID; используй методы и константы соответствующей библиотеки типов. На временном листе проверь создание линии и текста, сохранение и повторное открытие CDW. Затем создай рабочие листы из шаблона с рамкой и основной надписью. Задавай геометрию в координатах листа или вида с явными единицами и масштабом; наноси типовые символы, текст, размеры и таблицы как редактируемые объекты. Сохраняй каждый документ под своим шифром.

Если COM недоступен, открой КОМПАС через управление экраном. Создай чертёж, выбери формат и оформление, добавь виды, библиотеки УГО и таблицы. Вводи координаты и размеры в поля построения. Определяй элементы интерфейса по текущему окну, после каждой группы проверяй вид, масштаб и результат. Сохрани CDW и открой повторно. При отсутствии КОМПАС подготовь реестр, раскладку листов, таблицы и доступные документы; явно перечисли недостающие нативные листы.

Следующий перечень описывает содержание листов. Рабочую очередность задаёт раздел «Обязательная последовательность выпуска».

1. Функциональная схема. Размести оборудование и направления потоков, точки измерения, приборы по месту и на щите, управляющие воздействия, сигнализацию и связи. Покажи путь каждого контура. Назначай буквенные функции по реальной функции канала.
2. Принципиальная. Раздели питание, управление и сигнализацию. Покажи источники, защиту, нагрузки, катушки и соответствующие контакты, цепи управления и адреса продолжений. Проверь сценарии пуска, останова, срабатывания аварии, квитирования и восстановления по фактической логике задания.
3. СВС. Проведи каждую внешнюю цепь от полевого устройства до щита через фактические коробки и клеммы; укажи кабель, жилы, адреса концов и переходы между листами.
4. МКС. Построй внутренние соединения от клеммного ряда до конкретных зажимов аппаратуры. Граница СВС и МКС должна совпасть по щиту, клемме и цепи.
5. Щит. На фасаде покажи приборы, лампы, органы управления, рамки, вырезы и размерные привязки. На внутреннем виде задай направление наблюдения, панели, рейки, клеммы и каналы. Проверь глубину, коллизии, доступ и паспортные зазоры. Сформируй перечень по фактическому размещению. Отдельно сгруппируй надписи по типу рамки и заполни форму 6 по оригиналу. Сверь каждый номер с фасадом.

## Сверстай спецификацию

Сгруппируй одинаковые закупочные исполнения с сохранением всех позиций. Штучные количества вычисляй по экземплярам, метраж — по сумме маршрутов одного исполнения. Сверстай пробный лист в штатной форме с реальными переносами, заголовками и штампами. Если итог занимает один или два листа, выпусти единую спецификацию. При трёх и более листах раздели на два документа или явно озаглавленных раздела:

1. Приборы и средства автоматизации — датчики, вторичные приборы, регуляторы, ПЛК, клапаны с приводами, блоки питания и сигнализации.
2. Монтажные изделия и электроаппаратура — автоматы, пускатели, тепловые реле, кнопки, переключатели, лампы, звонки, DIN-рейки, клеммы, провода и кабели с метражом.

Проверь равенство итогов до и после разделения по артикулу и единице. Сохрани читаемый размер текста. В приложенном примере у клапанов перечислены четыре позиции при количестве три: вычисляй количество по реестру. Массу бери из паспорта в единицах графы.

## Подготовь пояснительную записку для обоих режимов

Создай редактируемый DOCX в Word или через python-docx. Настрой A4, Times New Roman 14 пт, интервал 1,5, поля слева 25, справа 10, сверху и снизу 20 мм по заданию. Определи стили основного текста, заголовков, подписей и таблиц. Включи титульный лист, содержание с обновляемыми полями, введение, описание процесса, выбор параметров, функциональную схему, обоснование приборов по каждому контуру, работу сигнализации и управления, настройку регуляторов, монтаж, выводы, источники и необходимые приложения. Согласуй порядок со структурой приложенных работ. Исключи экономические расчёты, сметы, амортизацию, ФОТ и окупаемость из текста, содержания и приложений.

Для каждого контура объясни измерение, преобразование сигнала, действия регулятора или сигнализации и результат. Параметры ПИД выводи из данных модели или опыта; при их отсутствии опиши методику настройки и обозначь недостающие данные. Таблицу назови сверху, рисунок подпиши снизу, сошлись на них в тексте. Формулы набери редактируемыми, пояснения начни со слова «де» без двоеточия. Обнови оглавление, номера страниц и ссылки, проверь переносы и фактический вид страниц.

## Приёмка

Сравни фактически сохранённые файлы с составом режима. Считай обозначения из CDW через API или сверь их на повторно открытых листах с отфильтрованными по назначению позициями реестра. Из DOCX извлеки текст и таблицы. Проследи один измерительный контур, одну аварийную цепь и каждый тип исполнительного устройства от функциональной схемы до закупки; автоматически сравни все связи по id, клеммам и номерам жил. Проверь уникальность номеров надписей с учётом тиража, все выноски и количество изделий. Просмотри каждый лист в масштабе печати на обрезку, наложения, пустые страницы и незаполненные штампы. Исправь расхождения и повтори проверку. Передай файлы, версию реестра, допущения и конкретные ограничения проверки.

## Контроль по приложенным образцам

Для спецификации открой 01_normy/DSTU/dsty_b_a.2.4-10-2009.pdf. Это восьмистраничный скан; просмотри страницы с формой и правилами заполнения визуально. Образец Специф_кац_я.jpg используй для сравнения компоновки.
Сопоставляй образцы построчно. На функциональной схеме М1 обозначает привод мешалки, М2 — насос; в таблице надписей строки 10 и 11 называют компрессоры. Выводи текст из назначения соответствующего двигателя. На листах встречаются ТРМ10 и ТРМ12; проверь выбранное исполнение по паспорту и вырежи отверстие только по его размерному чертежу. В спецификации Belimo перечислены 1в, 2в, 7в, 8в при количестве 3. Уточни число физических приводов по контурам и перечисли каждый ровно один раз.

## Развёрнутая ФСА и компоновка Э3 для преподавательского эталона

Применяй развёрнутый способ по 4.3.5–4.3.6 ДСТУ Б А.2.4-3:2009. Вверху воспроизведи топологию исходной ТХ, различимые силуэты и штуцеры аппаратов. Сохрани обводы регулирующих узлов, запорную арматуру и обходные пути по исходной технологии. Если обвязка не задана, обоснуй наличие или отсутствие байпаса для конкретного узла. Встроенный прибор ставь в разрыв коммуникации, установленный на аппарате — возле него по 4.3.6.1.
Заведи справочник сред, включая пар, газы, жидкости и другие потоки. Согласуй маркировку с ТХ; при отсутствии схемы ТХ используй источник кодов по 4.3.4 (приложение 3 ГОСТ 14202). Фиксируй основание для проектных номеров. По образцу преподавателя справа над штампом помести таблицу «Номер — Назва середовища». Сверь каждую маркированную трассу и её ответвления с таблицей. Номера 30–33 принадлежат конкретному примеру. Назначь отдельные стили технологическим трубопроводам и сплошным тонким сигнальным линиям.
